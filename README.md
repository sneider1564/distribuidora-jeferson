# Distribuidora Jeferson

Aplicación web desarrollada en **Angular**[cite: 6] para la gestión y consulta de inventario y operaciones de una distribuidora comercial.

## Stack tecnológico
- **Frontend:** Angular, TypeScript, HTML5, CSS3[cite: 6]
- **Control de versiones:** Git / GitHub

## Estructura principal
- `src/app`: Componentes, servicios y lógica principal de la aplicación[cite: 6].
- `public`: Recursos estáticos del proyecto[cite: 6].

## En desarrollo activo
- Mejora de componentes de interfaz y experiencia de usuario.
- Validaciones de formularios y manejo de estados en la aplicación.
- Optimización y organización del código fuente en `src/app`[cite: 6].
